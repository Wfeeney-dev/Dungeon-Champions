## 🗺️ About

**Dungeon Champions** is my first ever game. It's a small 2D dungeon crawler, built to learn C++ from the ground up.

The code is written by hand. I use AI only sparingly, to explain concepts, not to write the game. Most art is either downloaded or generated, since my focus is on programming rather than pixel art.

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/Wfeeney-dev/Dungeon-Champions.git
   ```
2. Open `DungeonChampions.sln` in Visual Studio 2022.
3. Build and run (`Ctrl + F5`).

## 📁 Project Structure

```
Dungeon-Champions/
├── assets/          # Sprites and images (title screen, etc.)
```
